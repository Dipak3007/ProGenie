# progenie-web

Angular 21 front end for ProGenie (standalone components, zoneless, signals, Tailwind CSS v4).

```bash
npm ci          # install exact versions from package-lock.json
npm start       # http://localhost:4200 (proxies /api to http://localhost:8080)
npm test        # unit tests (Vitest)
npm run build   # production build in dist/web/browser
```

See [../docs/LOCAL_SETUP.md](../docs/LOCAL_SETUP.md) for the full setup and the folder structure.
